# Auto tune Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan with test-first verification.

**Goal:** Offer the reviewed context-only correction through a Context correction slider and an Auto tune preset supplying its value; no glide handling.

**Architecture:** Scale the existing Viterbi decoder's contextual additions using effective control values only. Presets are recipes, never algorithm switches. Preserve legacy scoring at Context correction 0%, use v2 when the new control is active or explicitly overridden, and retain v1 decoding and wire codes.

**Tech Stack:** React, TypeScript, Vitest; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-30-auto-tune-design.md`

## Global constraints

- Clean remains default; glide handling is deferred to #50.
- No source-audio mutation or permanent CLI changes.
- Keep old preset semantics and wire codes unchanged.
- Context correction is available under every preset; Pull into key and Smooth leaps scale its respective contributions. Strong correction can alter deliberate chromatic notes.

## Review focus

- Old portable links/MIDI must retain pitches and bytes.
- New preset must survive share/MIDI/WAV round trips, including edits and mutes.
- Explicit keys, no detected key/silence, and slider endpoints must stay usable.
- Stored fixed segments and live audio must use the same scoring.
- Timing, segmentation and late D# notes must stay unchanged in pitch-only comparisons.
