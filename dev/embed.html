Embed playground

A sample lesson page with an editable tune or recording studio. Play and edit “Fly me to the moon” inside the frame, or switch to recording. Drag the frame’s bottom-right corner to resize it. 


  

    The two loopback hosts are different origins and both qualify as secure contexts. Production
    hosts must use HTTPS and permit the studio origin in their Permissions-Policy. Uncheck
    microphone delegation to test the error and retry flow. Reloading the studio ends the current
    take.
  

  

    Check setup scrolling, recording/Stop, automatic Editor navigation, Tune, note inspection,
    audio/MIDI playback, MIDI download, and Delete recording to start over. The Library should never
    appear. Storage belongs to the iframe origin; cross-site privacy settings may restrict it.
  

  

    Play the tune, edit pitches, and try Undo/Redo. Refresh the frame to recover temporary work.
    Save in the actions menu creates a Library recording and opens its editor. Capture and Library
    navigation stay unavailable. This example needs no microphone permission. Reload studio starts
    from the example link again; it does not delete saved recordings. Session and recording storage
    belong to the iframe origin and may be restricted by browser privacy settings.
